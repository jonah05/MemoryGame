# MemoryGame
Simple memory game with HTML, CSS and JavaScript

Memory Game is a classic memory-matching game built with HTML, CSS and JavaScript. The goal of the game is to find all matching pairs of cards using the fewest number of attempts.

Features:

-Interactive card flipping animations for a smooth user experience.

-Live attempt counter that updates as you play.

-Cards are shuffled every time the game starts or restarts.

-Winning message displayed when all matches are found.
